# 책장 스캐너 (find_my_book)

책장을 카메라로 찍으면 책등 글자를 읽어 책 목록을 만들어 주는 웹 앱입니다.
인식은 오픈소스 OCR인 [tesseract.js](https://github.com/naptha/tesseract.js)로
**브라우저 안에서** 처리합니다. 서버도, API 키도, 사진 업로드도 없습니다.

## 화면 흐름

1. **촬영** 탭에서 책장을 찍습니다. 넓은 책장은 최대 4장까지 나눠 찍을 수 있습니다.
2. **목록 만들기**를 누르면 브라우저가 책등을 한 권씩 잘라 글자를 읽습니다.
3. 잘못 읽은 제목은 그 자리에서 고치고, 책이 아닌 항목은 체크를 해제합니다.
4. **서재에 담기**를 누르면 중복을 걸러 저장합니다. 저장 위치는 브라우저 localStorage입니다.
5. **내 서재** 탭에서 검색하고 CSV나 JSON으로 내보냅니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
```

빌드해서 아무 정적 호스팅에나 올려도 됩니다. 백엔드가 필요 없습니다.

```bash
npm run build
npm run preview
```

### 완전 오프라인으로 쓰기

기본값에서는 언어 데이터(약 4MB)만 처음 한 번 공개 CDN에서 받아 옵니다.
그것마저 없애려면 미리 받아 두고 경로를 바꿔 주세요.

```bash
npm run fetch:langdata            # public/tessdata 에 eng, kor 저장
VITE_TESSDATA_PATH=/tessdata npm run build
```

OCR 워커와 wasm 코어는 이미 앱과 함께 배포됩니다. `npm install` 뒤 빌드할 때
`scripts/copy-tesseract-assets.mjs`가 `public/tesseract`로 복사합니다.

### 휴대폰에서 카메라 쓰기

브라우저는 `localhost`가 아닌 주소에서 **HTTPS일 때만** 카메라를 열어 줍니다.
휴대폰에서 테스트하려면 터널로 HTTPS 주소를 만들어 접속하세요.
카메라를 못 여는 환경에서는 **사진 선택** 버튼으로 갤러리 사진을 씁니다.

## 어떻게 읽는가

사진 한 장을 통째로 OCR에 넣으면 옆 책 글자가 한 줄로 섞여 읽힙니다.
그래서 책등을 먼저 나눈 뒤 한 권씩 읽습니다.

1. **기울기 추정** — 에지를 여러 각도로 기울여 투영해 가장 날카로운 각도를 찾습니다.
   손으로 찍은 사진은 대개 몇 도씩 기울어 있고, 그대로 두면 경계가 끊겨 보입니다.
2. **책등 분할** — 기울기를 따라 내려가며 열마다 "가장 긴 연속 세로 에지"를 잽니다.
   책 경계는 위아래로 길게 이어지고 글자 획은 짧게 끊기므로 이 값으로 갈라집니다.
3. **세로 구간 잘라내기** — 밴드마다 책이 실제 차지하는 위아래 범위를 찾아 자릅니다.
   위쪽 배경이 섞여 들어가면 OCR이 아무것도 못 읽고 통째로 실패합니다.
4. **양방향 인식** — 책등 글자는 위→아래거나 아래→위입니다. 두 방향 모두 읽습니다.
5. **방향 고르기** — 페이지 전체 신뢰도는 거꾸로 읽은 글자에도 높게 나와 못 믿습니다.
   글자 수로 가중한 단어 신뢰도에 기호 범벅과 짧은 결과를 깎아 고릅니다.
   진 쪽 결과도 남겨 두어, 화면에서 "다른 방향"을 눌러 뒤집을 수 있습니다.
6. **제목 보정** — Open Library에서 찾아 정식 제목과 표지를 붙입니다. 오탈자 교정도 겸합니다.
   네트워크가 막혀 있으면 이 단계만 조용히 건너뜁니다.

책등을 나누지 못하면 사진 전체를 세 방향으로 읽어 줄 단위로 건지는 방식으로 물러섭니다.

## 정확도

합성 책장 사진(가로로 늘어선 영문 책등 10권, 1.2도 기울임, 사진처럼 흐리게 처리)으로
측정했을 때 10권 중 9권을 제목까지 맞게 읽었습니다. 나머지 한 권은 옆 책과 한 밴드로
묶여 두 제목이 섞였습니다. 실제 사진은 이보다 조건이 나쁩니다.

- **한국어는 영어보다 많이 약합니다.** Tesseract의 한글 모델은 회전된 책등 글자에서
  자주 틀립니다. 제목 일부만 맞는 경우가 흔하니 화면에서 고쳐 쓰세요.
- 글자가 작거나 가려진 책등, 반사가 심한 표지는 놓칩니다.
- Open Library는 한국어 도서 수록이 고르지 않아 표지가 안 붙는 책이 많습니다.

### 잘 찍는 요령

- 책장 한 칸이 화면에 꽉 차게, 정면에서 찍습니다. 멀리서 전체를 담으면 글자가 뭉갭니다.
- 책등에 그림자나 반사가 생기지 않게 합니다.
- 넓은 책장은 칸별로 나눠 찍은 뒤 한 번에 읽는 편이 정확합니다.

## 성능

한 권마다 두 방향을 읽으므로 책 수에 비례해 시간이 듭니다. 데스크톱에서는 열 권 남짓에
수십 초, 휴대폰에서는 그보다 더 걸립니다. 언어 데이터는 처음 한 번만 받아 캐시합니다.
"영어만"으로 두면 눈에 띄게 빨라집니다.

## 구조

```
src/lib/segment.ts   기울기 추정, 책등 분할, 크롭 생성
src/lib/ocr.ts       tesseract 워커 관리, 양방향 인식, 방향 선택, 텍스트 정리
src/lib/enrich.ts    Open Library 조회 (실패해도 무시)
src/lib/storage.ts   localStorage 서재, 중복 제거, CSV/JSON 내보내기
src/components/      카메라, 인식 결과 편집, 내 서재 화면
scripts/             tesseract 자산 복사, 언어 데이터 내려받기
```
